## Residuals (open, tracked)

- **React `removeChild` console errors x2 around Start.** Investigated
  2026-08-25 after the release: two systematic reproduction attempts (dev and
  production React builds, same sequence -- Start, first reports landing,
  sample dropdown held open across refreshes) no longer fire it on current
  code. Both prior sightings ran pre-`c134e56` code, where the false
  "no data" badges flapped in the open dropdown as data landed -- the likely
  DOM-churn trigger, removed by that fix. Downgraded to closed-unproven;
  reopen if it recurs.
- **Quick-start toggle OFF removes a merged shared entry from another active
  list** (129 -> 128). Pre-existing merge/unload wart, out of round-3 scope.
- **ENOSPC ballast drill not run live** (unit-covered by the disk gate and
  the staleness surface); **kill-during-startup fix** verified by unit test,
  not re-run live.
- Fresh-process corrupt-report boundary: with no last-good frame in the new
  process, the sample drops from the aggregate union instead of flagging
  stale. By design; a future marker ("sample present on disk, unparseable")
  would close it.
